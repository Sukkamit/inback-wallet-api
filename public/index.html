⚡ ปุ่มจำลองสถานการณ์ 5 เคสสำคัญ (One-Click Scenario Testing)
1. UID ผิดพลาด (Invalid UID)
จำลองบอทแจ้ง UID ผิด (FAILED) ลูกค้าได้รับแจ้งเตือน และกดปุ่มแก้ UID ส่งคิวใหม่ได้ทันที
2. Transient Error (เซิร์ฟเวอร์หลุด)
บอทพบปัญหาชั่วคราว (Provider 503 / Network) ระบบส่งกลับคิว QUEUED พร้อม Exponential Backoff
3. Bot ดับ/ค้าง (Lease Expiry)
บอทรับงานแล้ว Crash ไม่ส่ง Heartbeat ระบบตรวจพบ Lease ขาด ดึงงานกลับคิวให้อัตโนมัติ
4. จ่ายเงินไม่ครบ (Underpayment)
ยอดออเดอร์ 200 แต่โอนมา 150 บาท Webhook แจ้งเตือนยอดขาด และระงับคิวไว้รอชำระเพิ่ม
5. สินค้าหมด / คืนเงิน (Auto Refund)
แพ็กเกจหมดกะทันหัน หรือลูกค้ายกเลิก ระบบตัดเงินคืนเข้าวอลเล็ต ปรับสถานะเป็น REFUNDED
➕ สร้างออเดอร์ใหม่ (New Order)
Order No เกม / แพ็กเกจ UID / Server ยอดเงิน สถานะ บอท / รายละเอียด การทำงาน (Actions)
